# Приватность

[English](privacy.md) · 19 ноября 2026

Strum ничего о тебе не собирает. В нём нет аккаунтов, аналитики, рекламы и отчётов о сбоях.

## Что остаётся на компьютере

Песни, их дорожки, твои записи, настройки и свои файлы комбиков лежат в `C:\Users\<ты>\Strum`. Python, скачанные модели и журналы — в `%LOCALAPPDATA%\app.strum`. Strum ничего из этого никуда не отправляет.

Strum слушает звуковой вход, выбранный в Настройках, чтобы гитара звучала через комбик. Этот звук обрабатывается на компьютере и сохраняется, только пока нажата Запись.

## Когда Strum выходит в интернет

Только в этих случаях:

| Когда | Что скачивается или отправляется | Куда |
|---|---|---|
| Установка, если в Windows его нет | Microsoft Edge WebView2 — окно, в котором работает Strum | Microsoft |
| Первый запуск | Python и его пакеты | github.com, pypi.org |
| Ты нажал **Скачать** на экране Песни | пакеты и модели разбора песен | pypi.org, download.pytorch.org, huggingface.co, cloud.cp.jku.at |
| Ты попросил распознать слова вокала | модель для слов | huggingface.co |
| Ты нажал **Найти текст в интернете** | отправляются исполнитель, название и длина песни | lrclib.net |

Эти сайты видят твой IP-адрес, как при любой загрузке, и у них свои правила приватности. Больше Strum им ничего не отправляет.

Окно Strum — это Microsoft Edge WebView2. Windows отправляет его диагностические данные в Microsoft так, как разрешено в твоих настройках диагностики Windows, как и для Edge.
